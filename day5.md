# WordPress Assignment — Themes & Plugins
## Task 1: Implement Core Concept — Themes & Plugins
### Themes
A Theme controls the design and layout of your website.
### Examples
- Astra
- Twenty Twenty-Four
- freddo
#### Steps to Install Theme
1. Login to WordPress Dashboard
2. Go to Appearance → Themes
3. Click Add New
4. Search "freddo"
5. Click Install
6. Click Activate

### Plugins
Plugins add extra features to your website.
#### Examples
- One click demo import
- SEO Plugin
#### Steps to Install Plugin
1. Go to Plugins → Add New
2. Search "one click demo import"
3. Click Install Now
4. Click Activate

5. Click Publish

### Theme Customization
