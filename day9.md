# Day 9 Task - ELEMENTOR

## Task 1: Implement Core Concept – Elementor

Elementor is a drag-and-drop page builder used to design WordPress websites visually without coding.

### Core Concepts:
- Sections, Columns, Widgets structure
- Live front-end editing
- Responsive design controls
- Pre-built templates and blocks

### Steps:
1. Install and activate Elementor plugin
2. Go to Pages → Add New
3. Click "Edit with Elementor"
4. Add Sections → Columns → Widgets
5. Save and publish the page

---

## Task 2: Create / Configure Features in Elementor

### Features Implemented:
- Hero Section (Image + Heading + Button)
- About Section
- Services/Products Section
- Contact Form

### Steps:
1. Open page with Elementor
2. Add a new section
3. Drag widgets like:
   - Heading
   - Image
   - Button
   - Text Editor
4. Customize content and layout
5. Use templates if needed

---

## Task 3: Customize UI / Settings in Elementor

### Customizations:
- Typography (fonts, size, weight)
- Colors (background, text, buttons)
- Spacing (margin & padding)
- Responsive design (mobile/tablet view)

### Steps:
1. Click on any widget
2. Go to:
   - Content tab → Edit text/images
   - Style tab → Change colors, fonts
   - Advanced tab → Adjust spacing
3. Use Responsive Mode (bottom panel)
4. Adjust layout for mobile devices

---

## Task 4: Debug / Optimize Elementor

### Issues & Fixes:

#### 1. Page not loading properly
- Clear cache
- Regenerate CSS (Elementor → Tools)

#### 2. Mobile view issues
- Use responsive settings
- Adjust font sizes and spacing

#### 3. Slow loading
- Optimize images
- Use lightweight theme
- Disable unused plugins

#### 4. 404 Error
- Go to Settings → Permalinks → Save changes
