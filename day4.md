#  WordPress Tasks – Posts, Pages, Media
#  Task 1: Implement Core Concept: Posts, Pages, Media
##  Posts
Posts are used for blog content. They appear in reverse chronological order.
### Steps:
1. Login to WordPress Dashboard  
2. Go to Posts → Add New  
3. Enter Post Title  
4. Add Content  
5. Select Category  
6. Add Featured Image  
7. Click Publish  
### Example:
- Title: My Fitness Blog  
- Content: Welcome to my first blog  
##  Pages
Pages are used for static content like Home, About, Contact.
### Steps:
1. Go to Pages → Add New  
2. Enter Page Title  
3. Add Content  
4. Click Publish  
### Example Pages
- Home  
- About  
- Contact  
- Services  
##  Media
Media is used to upload images, videos, documents.
### Steps:
1. Go to Media → Add New  
2. Upload File  
3. Insert into Post/Page

#  Task 4: Debug / Optimize Scenario
## Issue 1: Post Not Showing
### Solution
- Check Publish Status  
- Check Category  
- Check Permalink  
## Issue 2: Page Not Updating
### Solution
- Clear Cache  
- Click Update  
- Refresh Page  
## Issue 3: Image Not Showing
### Solution
- Check Image Upload  
- Check Image URL  
- Reinsert Image
