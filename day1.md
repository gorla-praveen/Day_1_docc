# Static vs Dynamic Websites & WordPress Overview

## Task 1: Core Concepts

### Static Website
- Fixed content (HTML, CSS)
- No database or backend
- Fast and simple
- Example: Portfolio site

### Dynamic Website
- Content changes based on user interaction
- Uses backend (PHP, MySQL)
- Supports login, comments, etc.

---

## WordPress Overview
WordPress is a Content Management System (CMS) used to create dynamic websites easily.

### WordPress.org vs WordPress.com

| Feature | WordPress.org | WordPress.com |
|--------|--------------|---------------|
| Hosting | Self-hosted | Hosted |
| Control | Full control | Limited |
| Plugins | Allowed | Limited |
| Cost | Paid hosting | Free + Paid plans |

---

## Task 2: Feature Implementation

- Install WordPress
- Create Pages (Home, About, Contact)
- Add Posts (dynamic content)
- Install plugins (e.g., contact form)

---

## Task 3: UI Customization

- Go to Appearance → Themes
- Customize colors, fonts, logo
- Set homepage:
  - Static page or blog feed
- Configure menus and widgets

---

## Task 4: Debug & Optimization

### Common Issues
- Slow site → Use caching
- Plugin conflicts → Disable plugins
- Theme errors → Switch theme

### Optimization Tips
- Use lightweight themes
- Compress images
- Minimize plugins

---

## Task 5: Demo Output

### Static Site
- Fixed content
- No interaction

### Dynamic WordPress Site
- Blog posts (auto-updating)
- Comments enabled
- Contact form

---

## Conclusion
- Static websites are fast but limited
- Dynamic WordPress sites are flexible and interactive
- WordPress.org offers full control
- WordPress.com is beginner-friendly
