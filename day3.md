- The Dashboard is the main control panel of WordPress where users manage website content, settings, and features.

2. Open Browser
3. Enter URL:

## Permalinks
Definition
- Permalinks are the permanent URLs of posts and pages.
### Steps to Configure Permalinks
- Go to Dashboard
- Click Settings
- Click Permalinks
- Select Post Name
- Click Save Changes
Example
Default URL
http://localhost/praveen-com/sample-post

## Categories
Definition
- Categories are used to group related posts.
### Steps to Create Category
- Go to Dashboard
- Click Posts
- Click Categories
- Enter Category Name
- Click Add New Category


## Tags
Definition
- Tags are used to describe details of posts.
### Steps to Create Tags
- Go to Dashboard
- Click Posts
- Click Tags
- Enter Tag Name
- Click Add Tag
