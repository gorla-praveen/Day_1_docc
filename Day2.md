# Objective
- To set up a local hosting environment using XAMPP and successfully install and run a WordPress website, along with demonstrating the output.
# Task 1:-Core Concepts
## Web Hosting
   - Web hosting is a service that allows websites to be published on the internet.
   - Hosting providers store website files on servers and make them accessible via a domain
  
 ## XAMPP
  - XAMPP is a local server environment used to run websites on a personal computer.
 - Components:
    - Apache (Web Server)
    - MySQL (Database)

# Task 2: Create/Configure Features
## Step 1: Install XAMPP
  - Download and install XAMPP
  -  Open Control Panel
  -  Start Apache and MySQL
##  Step 2: Setup WordPress
  - Download WordPress
  -  Extract files
  -  Place in C:\xampp\htdocs\praveen
##  Step 3: Configure Database
   -  Open http://localhost/phpmyadmin    
  - Create database: wp_admin
